# HDMaps26

Crew route sheet for the North Side sign runs.

- **Run 1:** Lake Shore Drive south (Hollywood to North Ave), then the Red Line north (North/Clybourn to Bryn Mawr).
- **Run 2:** Irving Park west from the lake, then Addison east back to the lake.

Each run puts up 100 signs: 10 stops per street, 5 named spots per stop. Open the site on a phone and tap each spot as its sign goes up.
